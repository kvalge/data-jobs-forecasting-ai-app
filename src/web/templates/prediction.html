{% if baseline_only %}

Baseline only — what these results mean

You ran baseline alone. That is not a forecast of future months. It summarizes history inside the training window for the shortlisted roles and skills:

  • Value = latest monthly posting count (most recent month in the window).
  • Horizon is always 0; Period is empty.
  • Stored metrics (see DB / export) include moving averages (3 / 6 / 12 months when available), period-over-period growth %, and a simple linear trend (up / down / flat).

To see future months (3 / 6 / 12), also select forecast models such as arima or prophet (they need enough monthly history per target).

{% else %}

How to read forecast results

  • role / skill — predicted posting volume for that future month.
  • salary_role — predicted average salary for that role (rounded).
  • baseline_role / baseline_skill — historical latest count only (horizon 0), if baseline was selected.
  • Horizon — months ahead (3, 6, or 12). Period — calendar month-start of that step.
